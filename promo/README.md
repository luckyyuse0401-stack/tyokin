# ZUBO 宣伝素材（製作者アカウント用）

TikTok（1080×1920）向けの動画・静止画を、本物のアプリを動かして作るためのスクリプト。

| ファイル | 内容 |
|---|---|
| `common.js` | ステージ（見出し＋スマホ枠＋アプリのiframe）と、デモ用データ（名前「ずぼら」・3か月分の記録・目標100万円）の投入 |
| `ad3.js` | 初投稿・第1話（約18秒）。イラストの手・ぼかし背景・タップ音のタイミング記録つき |
| `video2.js` | シンプル版（スマホ画面のみ・約14秒） |
| `stills.js` | 静止画6枚 |
| `apple_shots.js` → `apple.js` | アップル風15秒（素材の撮影 → 1コマずつ描画）。`node apple_shots.js && node apple.js` のあと `ffmpeg -framerate 30 -i cm/f2/%04d.jpg ...` でmp4に |
| `apple2_shots.js` → `apple2.js` | アップル風 第2弾（約14秒）：今月のまとめ・毎月かかるお金。最後は「次は、どんな機能が欲しいですか？」。素材とコマは `cm2/` |
| `kanojo_shots.js` → `kanojo_slides.js` | 彼女目線の写真投稿8枚（`lv/s1〜8.png`） |
| `kanojo_video.js` | 彼女目線の画面録画風動画 |

## 決めたこと（製作者アカウント）
- 撮影はしない。画面は本物のアプリ、手と背景はイラスト
- 宣伝用は残高を最初から表示（アプリ本体は隠したまま）
- 第1話の構成：開発ストーリーの冒頭 →「1千→200→コンビニ」の2タップ入力 → 残高が減る → 貯金予測をカウントアップ → 質問は1つ（「ほしい」とコメント）＋「作ってる過程も載せていきます」
- 1本1ネタのシリーズにする（クレカ編、彼女編、コメント返し など）
- 効果音は ffmpeg で合成（pop / ding / whoosh / count）。BGMは TikTok 側で重ねて音量20〜30%

## 動かし方
アプリを `python3 -m http.server 8765` で配信した状態で、Playwright（Chromium）と ffmpeg を使って `node ad3.js` を実行し、記録された webm を ffmpeg で切り出し・効果音を合成する。
