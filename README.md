# のこり（tyokin）

ズボラでも続く、シンプル残高管理アプリ。スマホのブラウザで開いて「ホーム画面に追加」して使います。

## できること
- 金額ボタンをタップ → 「コンビニ」「ごはん」などを1タップで支出登録（メモは任意）
- カレンダーで日ごとの支出を確認。引き落とし日は赤丸、給料日は緑丸
- カードの引き落とし額を先に入れておくと、その日に自動で残高から引かれる
- 毎月の給料・家賃などは金額を登録しておけば自動で反映
- アカウントごとに4桁のパスコード
- 機種変更は「引き継ぎリンク」（パスコードで暗号化）またはバックアップファイルで

## データの保存場所
データはサーバーには送らず、各スマホのブラウザ（localStorage）にだけ保存します。

## 公開方法（GitHub Pages）
1. リポジトリを Public にする
2. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/tyokin/` で開けます

ビルド不要の静的ファイル（`index.html` / `style.css` / `app.js` / `sw.js`）だけで動きます。
